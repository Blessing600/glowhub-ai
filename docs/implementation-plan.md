### Decisions
- **Single app instead of `apps/web` + `packages/*`.** The brief's layout is "suggested";
  a workspace monorepo adds build and memory overhead on the current dev machine with no
  second consumer yet. Shared code lives in `src/lib`, `src/config`, `src/types` with no
  React imports in pure logic, so it can move to packages unchanged.
  See `docs/frontend-architecture.md`.
- **Base dusty rose fails AA for body text** (3.53:1 on cream). It is limited to large
  text, UI graphics and the logo; `rose-700` carries rose-coloured text.
- **`cn` package.** Current shadcn emits `import { cn } from "cn"` (published by the
  shadcn maintainer, no install scripts) instead of a local clsx/tailwind-merge helper.
- **Playwright on macOS 12** uses installed Chrome (`PLAYWRIGHT_CHANNEL=chrome`).

### Open issues / dependencies
- Photography: no licensed imagery supplied yet. M2 needs hero, editorial and product
  images; placeholders will be clearly labelled and listed for replacement.
- Brand palette, wordmark and monogram are prototype proposals pending brand approval.
- Docs still to write in later milestones: `mock-data-model` (M5), `integration-contracts`

### Post-milestone fix (16 Nov 2026)
- `naira()` rounded through raw float multiplication, so `naira(1.005)` gave 100 kobo
  instead of 101. It now trims float error before rounding and rounds half-kobo away
  from zero, matching `applyRate`. Regression test added. `npm run test` — 38 passed;
  typecheck and lint clean.

### Open decision — Glow Scan placement
The PRD makes image analysis a gated P1 pilot, "not a launch promise", and says the
site should lead with B2B value. The brief adds a consumer Glow Scan (M3) and a "Try
Glow Scan" header CTA (M2). Safeguards make it safe, but a header CTA presents it as a
headline feature. **Needs a product decision before M2 ships the header:** keep the
header CTA, limit Glow Scan to the shopper page and demo, or label it clearly as a
preview. Until decided, M2 builds the header with Glow Scan behind a single constant so
it is a one-line change.
